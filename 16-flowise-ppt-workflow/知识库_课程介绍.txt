Python AI 全栈课程知识库

一、课程简介
本课程是一套面向中文学习者的 Python 人工智能全栈开发实战课程，覆盖从深度学习基础到大模型应用开发的完整路线。课程内容分为基础层、模型层、应用层三个层次，全部案例基于本地 GPU（RTX 4060 Laptop）环境开发与验证。

二、基础层：深度学习与模型训练
1. PyTorch 深度学习：张量运算、自动求导、数据集与 DataLoader、卷积神经网络（CNN）图像分类，使用 ResNet18 在自建数据集上完成训练与验证，训练全程使用 CUDA 加速。
2. 计算机视觉项目：图像分类、目标检测与图像分割的原理与实战，掌握迁移学习（fine-tune）方法。
3. 模型部署：训练好的模型通过 TorchScript、ONNX 等方式导出，并结合 Web 服务对外提供推理接口。

三、模型层：Transformer 与大模型
1. Transformers 库：Hugging Face 生态，pipeline、tokenizer、model 三大核心对象，加载本地模型进行文本分类、问答、摘要、语音识别（Whisper large-v3 本地部署）等任务。
2. 大语言模型：ChatGLM、Qwen 等开源模型的本地部署与对话，理解 prompt 工程、上下文长度与推理参数（temperature、top_p、repetition_penalty）。
3. 语音合成与声音克隆：使用 Coqui TTS 的 XTTS-v2 模型实现零样本（zero-shot）中文声音克隆，仅需 6-30 秒参考音频即可生成目标音色语音。
4. 文生图：Stable Diffusion XL 模型本地推理，文生图、图生图、局部重绘与 LoRA 微调加载。

四、微调训练
使用 LlamaFactory 框架对开源大模型进行 LoRA 高效微调，包括数据集准备（alpaca 格式）、WebUI 操作、命令行训练、模型评估与合并导出，全部流程在本地 GPU 上完成。

五、应用层：AI 应用开发
1. LangChain：模型 I/O、链式调用、记忆、Agent 与工具调用，构建多步骤 AI 应用。
2. LangGraph：基于图结构的多智能体编排，条件路由、状态管理、人机协同，实战案例包括多智能体综艺讨论生成器。
3. Gradio：快速搭建模型演示界面，支持语音输入输出、画板交互、文件上传，并通过 @gradio/client 实现前端 Svelte 应用与后端 AI 服务的集成。
4. RAG 检索增强生成：文档加载、文本切分、向量嵌入（Embedding）、向量数据库存储与相似度检索，让大模型基于私有知识库回答问题。本节课使用 Flowise 可视化编排平台实现向量数据库问答系统。
5. Flowise 低代码平台：拖拽式编排 LLM 应用，节点包括文档加载器、文本切分器、Embeddings、向量库、聊天模型与问答链，支持一键发布为 API 与聊天窗口。

六、本地 LLM 部署
使用 LM Studio 在本地部署 GGUF 格式量化模型（如 Qwen3-0.6B、bge-m3 向量模型），通过 OpenAI 兼容 API（默认端口 1234）对外提供服务，实现完全离线的私有化 AI 能力。

七、课程特色
- 全中文讲解，案例可复现，配套源码与笔记
- 本地 GPU 优先，保护数据隐私，零 API 成本
- 从训练到部署到应用的全链路实战
