> 配套可视化工具：`特征值特征向量实验室.html`

## 一句话理解

矩阵作用在某个向量上，如果该向量的方向没有改变（只被拉伸或压缩），那么这个向量就是**特征向量**，而拉伸或压缩的倍数就是对应的**特征值**。

## 核心概念

想象你用手推一块橡皮泥，大多数方向上的点都会被扭曲、旋转，但总有一些特殊方向上的点，它们只沿着原来的方向被拉长或缩短，方向本身不变。这些"方向不变"的向量就是特征向量，对应的伸缩比例就是特征值。

对于 n 阶方阵 A，若存在非零向量 x 和标量 λ，使得 Ax = λx，则 λ 称为 A 的特征值，x 称为对应于 λ 的特征向量。特征值反映了矩阵在特定方向上的"缩放能力"，特征向量则指明了这些特殊方向。

## 原理与公式

**定义**：Ax = λx，其中 A 为 n 阶方阵，x ≠ 0。

**特征方程**：将定义改写为 (A - λI)x = 0，要使非零解存在，必须满足 det(A - λI) = 0。这个行列式等于零的方程就是特征方程，其根即为特征值。

**求解步骤**：
1. 计算 det(A - λI) = 0，得到关于 λ 的 n 次多项式方程；
2. 解方程求出所有特征值 λ₁, λ₂, …, λₙ；
3. 对每个 λᵢ，求解 (A - λᵢI)x = 0 得到对应的特征向量。

**重要性质**：n 阶矩阵恰好有 n 个特征值（含重数），特征值之和等于矩阵的迹（对角元素之和），特征值之积等于矩阵的行列式。

## 动手实验

1. **观察变换效果**：打开"特征值特征向量实验室"网页，选择一个 2×2 矩阵，点击"应用变换"，观察平面上所有向量被矩阵作用后的变化，注意哪些方向上的向量变换后仍然保持在原来的直线上。

2. **验证特征向量**：在网页中输入或选择一组已知的特征向量，观察变换前后该向量的方向是否保持不变，同时读取网页显示的伸缩比例，确认其等于对应的特征值。

3. **动态旋转探索**：使用网页中的旋转或拖拽功能，改变矩阵的参数，实时观察特征方向和特征值如何随之变化，体会不同矩阵（如对称矩阵、旋转矩阵）的特征结构差异。

## 学习要点

- **易错点**：特征向量必须是非零向量，零向量不满足定义；特征值可以为零，但对应的特征向量仍然非零。
- **记忆口诀**："方向不变叫特征，伸缩倍数是特征值；行列式为零求特征值，代入方程求特征向量。"
- **与对角化的联系**：若矩阵有 n 个线性无关的特征向量，则该矩阵可以对角化，即 A = PΛP⁻¹，其中 Λ 为对角矩阵，P 的列向量为特征向量。
- **几何直觉**：特征值特征向量揭示了矩阵变换的"骨架"——任何复杂变换都可以理解为在特征方向上的独立缩放（在可对角化的情况下）。
