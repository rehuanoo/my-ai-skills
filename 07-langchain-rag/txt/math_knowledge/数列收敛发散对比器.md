# 数列收敛发散对比器

## 一句话理解

通过动态生成数列点列并观察误差带 ε 的收缩过程，直观区分收敛数列与发散数列的本质差异。

## 核心概念

数列收敛发散对比器是一个可视化教学工具，它将抽象的数列极限概念转化为动态图像。工具同时展示多个数列（如 $a_n = 1/n$、$a_n = (-1)^n$、$a_n = n$ 等），以散点形式绘制点列 $(n, a_n)$。用户可设定一个目标值 $L$ 和误差带 $\varepsilon$，工具会画出 $L \pm \varepsilon$ 构成的水平带状区域。当 $n$ 足够大后，若所有点都落入该带内，则数列收敛于 $L$；若点持续逃逸出带外，则数列发散。这种"点列 vs 误差带"的对比方式，让收敛与发散从文字定义变为可观察的几何现象。

## 原理与公式

数列收敛的严格定义为：$\forall \varepsilon > 0, \exists N \in \mathbb{N}^+$，使得当 $n > N$ 时，$|a_n - L| < \varepsilon$。其中 $L$ 为极限值，$\varepsilon$ 为任意给定的正数（误差带半宽），$N$ 为对应的阈值。

发散则意味着上述条件不成立：存在某个 $\varepsilon_0 > 0$，使得对任意 $N$，总存在 $n > N$ 满足 $|a_n - L| \geq \varepsilon_0$。

对比器的核心逻辑即：固定 $L$ 和 $\varepsilon$，观察点列是否最终全部落入带状区域 $L - \varepsilon < a_n < L + \varepsilon$。

## 动手实验

1. **选择数列类型**：在工具中分别选择 $a_n = 1/n$（收敛于 0）、$a_n = (-1)^n$（振荡发散）、$a_n = n$（趋向无穷）三种典型数列，观察点列的走势差异。
2. **调节误差带 ε**：将 ε 设为 0.5，观察收敛数列的点列是否在有限项后全部进入带内；再将 ε 缩小至 0.1，注意 $N$ 值变大——这体现了"ε 越小，N 越大"的关系。
3. **对比发散数列**：对 $a_n = (-1)^n$ 设 $L = 0$，无论 ε 取多小，点列始终在带外振荡，直观感受"不存在这样的 N"的含义。

## 学习要点

- **易错点**：收敛要求"最终全部落入"，而非"偶尔落入"。$a_n = (-1)^n$ 虽然无穷次穿过 $L=0$，但从未最终停留在带内，因此发散。
- **记忆口诀**："ε 给多小，N 找得到，之后全在带里跑"——抓住 ε-N 定义的因果顺序。
- **联系**：本工具与"极限的 ε-N 定义"直接对应，是理解极限存在性判据（夹逼定理、单调有界定理）的几何基础。
- **注意**：收敛数列的极限唯一，工具中若改变 $L$ 值，收敛数列的点列将不再落入新带内。
