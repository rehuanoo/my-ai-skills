## 一句话理解

拖动 ε 带宽度，自动求出 δ 并高亮验证，直观理解极限的严格 ε-δ 定义。

## 核心概念

极限的直觉是"当 x 趋近 a 时，f(x) 趋近 L"，但"趋近"一词在严格数学中需要精确定义。ε-δ 语言正是这个精确化：对任意给定的正数 ε（误差带宽度），总能找到一个正数 δ，使得只要 x 与 a 的距离小于 δ（但不等于 a），f(x) 与 L 的距离就小于 ε。ε-δ 极限实验室将这一抽象逻辑转化为可视化操作：你设定 ε，系统自动计算满足条件的 δ，并在图像上高亮显示 ε 带和 δ 邻域，让你亲眼看到"δ 足够小则 f(x) 被限制在 ε 带内"这一核心关系。

## 原理与公式

极限的严格定义为：

$$\lim_{x \to a} f(x) = L \iff \forall \varepsilon > 0,\ \exists \delta > 0,\ \text{使得}\ 0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon$$

其中：
- ε 表示函数值 f(x) 与极限 L 之间的允许偏差（误差带宽度）
- δ 表示自变量 x 与 a 之间的允许偏差（邻域半径）
- 关键逻辑：先给 ε，再找 δ；δ 依赖于 ε 的大小

ε 越小（要求越严格），通常 δ 也越小（x 必须越靠近 a）。

## 动手实验

1. **设定 ε 值**：在网页中拖动 ε 滑块，观察水平方向上 L 上下各 ε 的误差带如何变化。注意 ε 带越窄，对 δ 的要求越严格。

2. **观察 δ 的自动计算**：系统根据当前 ε 自动求出满足条件的 δ，并在 x 轴上高亮显示 a 左右各 δ 的邻域区间。对比不同 ε 下 δ 的变化趋势，体会 δ 对 ε 的依赖关系。

3. **验证高亮区域**：观察在 δ 邻域内（排除 x = a 本身），函数曲线是否完全落在 ε 带内。尝试将鼠标悬停在曲线上，查看具体点的 |f(x) - L| 是否确实小于 ε，从而验证定义的成立。

## 学习要点

- **易错点**：δ 必须依赖于 ε，不能先选 δ 再找 ε；逻辑顺序是"∀ε ∃δ"而非"∀δ ∃ε"。
- **易错点**：条件 0 < |x - a| 排除了 x = a 本身，极限不要求 f(a) 存在或等于 L。
- **记忆口诀**："先给误差带，再找邻域圈；带窄圈必小，圈内不出带。"
- **知识联系**：ε-δ 定义是连续性的基础（连续即 lim f(x) = f(a)），也是理解无穷小量、导数定义的前提。
