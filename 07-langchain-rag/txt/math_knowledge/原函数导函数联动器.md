# 原函数—导函数联动器

## 一句话理解

在 x₀ 处，原函数 F(x) 的切线斜率恰好等于导函数 f(x) 在该点的函数值——拖动切线，两图同步变化，直观感受微积分基本定理。

## 核心概念

原函数与导函数是微积分中一对"互为逆运算"的函数。给定导函数 f(x)，其原函数 F(x) 满足 F'(x) = f(x)，即 F(x) 在任意点 x₀ 处的切线斜率就是 f(x₀)。联动器将 F(x) 画在上图、f(x) 画在下图，当你拖动上图 x₀ 处的切线时，下图同步标出 f(x₀) 的值，让你亲眼看到"斜率 = 函数值"这一核心关系。这正是微积分基本定理（FTC）的几何本质：导数描述变化率，原函数描述累积量，两者通过切线斜率紧密相连。

## 原理与公式

- **导数定义**：f(x₀) = F'(x₀) = lim(Δx→0) [F(x₀+Δx) − F(x₀)] / Δx，几何意义为 F(x) 在 x₀ 处切线的斜率。
- **微积分基本定理（FTC）**：若 f(x) 在 [a,b] 上连续，则 F(x) = ∫[a,x] f(t)dt 是 f(x) 的一个原函数，且 F'(x) = f(x)。
- **联动关系**：上图切线斜率 k = F'(x₀) = f(x₀)，下图在 x₀ 处的函数值恰好等于 k。当 f(x₀) > 0 时 F(x) 递增，f(x₀) < 0 时 F(x) 递减，f(x₀) = 0 时 F(x) 取极值。

## 动手实验

1. **观察初始状态**：打开联动器网页，注意上图 F(x) 曲线和下图 f(x) 曲线的对应关系，确认 x₀ 初始位置处切线斜率与 f(x₀) 数值一致。
2. **拖动切线**：将 x₀ 从左向右缓慢拖动，观察上图切线斜率从正变负（或反之）的过程，同时下图 f(x₀) 的值同步变化，验证"斜率=函数值"。
3. **寻找极值点**：将 x₀ 移动到 f(x₀) = 0 的位置，观察上图切线变为水平线，此时 F(x) 恰好取得极值，体会导数为零与极值的关系。
4. **对比变化趋势**：在 f(x₀) 绝对值较大的位置，观察上图切线更陡，下图 f(x₀) 的绝对值也更大，加深"变化率越大、曲线越陡"的直觉。

## 学习要点

- **易错点**：原函数不唯一，F(x) + C 都是原函数，但切线斜率（即导数值）与常数 C 无关，联动器展示的是斜率关系而非函数值关系。
- **记忆口诀**："上图看斜率，下图看数值，斜率等于数值，联动见真章。"
- **知识联系**：本知识点是 FTC 的几何可视化，与"定积分作为面积"和"牛顿-莱布尼茨公式"一脉相承，理解联动器有助于打通微分与积分的桥梁。
- **进阶思考**：若将 f(x) 换成 F''(x)，则联动关系变为"曲率与凹凸性"，可进一步探索高阶导数的几何意义。
