## 一句话理解

Gram-Schmidt正交化就像"反复投影再减去"——把一组线性无关的向量，通过逐步消除彼此之间的"重叠分量"，最终变为一组两两垂直的正交基。

## 核心概念

在向量空间中，我们常常拿到一组线性无关的向量，但它们之间并不垂直。Gram-Schmidt正交化是一种系统性的"改造"方法：从第一个向量开始，依次处理后续每个向量，将其在已处理向量上的投影分量逐一减去，剩下的部分就是与前面所有向量都垂直的新向量。整个过程就像在三维空间中"削掉"每个向量中与其他向量平行的部分，最终得到一组方向互不重叠的正交基。

## 原理与公式

设原始线性无关向量为 $v_1, v_2, \ldots, v_n$，正交化后的向量为 $e_1, e_2, \ldots, e_n$。

**第一步**：直接取 $e_1 = v_1$。

**第二步**：将 $v_2$ 在 $e_1$ 上的投影减去，得 $e_2 = v_2 - \text{proj}_{e_1} v_2$，其中 $\text{proj}_{e_1} v_2 = \frac{\langle v_2, e_1 \rangle}{\langle e_1, e_1 \rangle} e_1$。

**第 $k$ 步**：$e_k = v_k - \text{proj}_{e_1} v_k - \text{proj}_{e_2} v_k - \cdots - \text{proj}_{e_{k-1}} v_k$。

每一步的投影公式为 $\text{proj}_{e_i} v_k = \frac{\langle v_k, e_i \rangle}{\langle e_i, e_i \rangle} e_i$。若需要标准正交基，最后对每个 $e_k$ 做归一化：$u_k = \frac{e_k}{\|e_k\|}$。

## 动手实验

1. **观察初始状态**：打开"Gram-Schmidt正交化动画.html"，查看页面上显示的原始向量组（通常为二维或三维空间中的若干箭头），注意它们之间的夹角并非90°。
2. **逐步播放正交化过程**：点击"下一步"或"播放"按钮，观察动画如何依次处理每个向量——先画出当前向量在已正交化向量上的投影（通常用虚线或不同颜色表示），再执行减法操作，得到新的正交向量。
3. **对比投影与减法**：在每一步暂停，对比原始向量、投影分量和剩余分量三者之间的关系，验证"原始向量 = 投影 + 正交分量"这一分解。
4. **调整参数（如支持）**：尝试修改初始向量的方向或数量，观察正交化结果如何随之变化，加深对算法鲁棒性的理解。

## 学习要点

- **易错点**：投影公式中分母是 $\langle e_i, e_i \rangle$ 而非 $\langle v_k, v_k \rangle$，务必确认投影方向是已正交化的向量。
- **记忆口诀**："先投影，再相减，剩下来的就是正交分量"——每一步都在做"减去已知方向"的操作。
- **数值稳定性**：当向量接近线性相关时，Gram-Schmidt过程会产生较大的数值误差，此时应考虑改用QR分解中的Householder方法。
- **与其他知识的联系**：Gram-Schmidt正交化是QR分解的核心算法之一，也是求解最小二乘问题、计算特征值（如幂迭代法）的重要工具。
