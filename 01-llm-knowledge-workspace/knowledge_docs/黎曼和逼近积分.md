# 黎曼和逼近积分实验室

> 配套可视化工具：`黎曼和逼近积分.html`

## 一句话理解

把曲线下方的面积切成许多小矩形，矩形越窄、数量越多，总面积就越接近真实积分值——定积分就是当矩形宽度趋于零时黎曼和的极限。

## 核心概念

黎曼和是定积分的"离散近似"。给定函数 $f(x)$ 在区间 $[a, b]$ 上的积分，我们将区间等分为 $n$ 份，每份宽度 $\Delta x = \frac{b-a}{n}$。在每份上取一个代表点（左端点、右端点或中点），用该点的函数值乘以宽度得到一个小矩形的面积，所有小矩形面积之和即为黎曼和。当 $n \to \infty$ 时，黎曼和收敛于定积分的精确值。左黎曼和用每段左端点取值，右黎曼和用右端点取值；对于单调递增函数，左和总是低估、右和总是高估，二者夹逼出真实面积。

## 原理与公式

设 $[a,b]$ 被等分为 $n$ 个子区间，分点为 $x_i = a + i\Delta x$，其中 $\Delta x = \frac{b-a}{n}$。

- **左黎曼和**：$L_n = \sum_{i=0}^{n-1} f(x_i)\,\Delta x$
- **右黎曼和**：$R_n = \sum_{i=1}^{n} f(x_i)\,\Delta x$
- **定积分定义**：$\int_a^b f(x)\,dx = \lim_{n\to\infty} L_n = \lim_{n\to\infty} R_n$

核心思想：积分 = 无穷多个无穷窄矩形的面积之和。

## 动手实验

1. **观察初始状态**：打开"黎曼和逼近积分.html"，选择函数 $f(x) = x^2$，区间 $[0, 2]$，将矩形数量设为 $n=4$，观察左矩形和右矩形与曲线之间的偏差，注意左和低估、右和高估的现象。
2. **逐步增加矩形数**：将 $n$ 依次调为 8、16、32，观察矩形总面积如何逐渐逼近曲线下的真实面积（该例精确值为 $\frac{8}{3} \approx 2.667$），体会"越细越准"的极限过程。
3. **切换函数与对比**：换用 $f(x) = \sin(x)$ 在 $[0, \pi]$ 上，分别查看左和与右和的数值，验证二者从两侧夹逼精确值 $\int_0^\pi \sin x\,dx = 2$ 的结论。

## 学习要点

- **易错点**：左和与右和的求和索引不同（左和从 $i=0$ 到 $n-1$，右和从 $i=1$ 到 $n$），写错会导致结果偏差一个 $\Delta x$。
- **记忆口诀**："左低右高夹真值，矩形越窄越精确"——单调递增时左和偏低、右和偏高，二者之差随 $n$ 增大而趋于零。
- **知识联系**：黎曼和是定积分定义的基础，后续的微积分基本定理（牛顿-莱布尼茨公式）正是将这一极限过程转化为原函数求值，从而避免逐段求和。
- **进阶理解**：当函数非单调时，左和或右和可能同时高估或低估，此时可用中点黎曼和获得更优近似。
