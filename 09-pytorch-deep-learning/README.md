# 09 · PyTorch 深度学习实践（9 个专题）

> 从张量运算到 GAN，把深度学习的主干模型都亲手实现一遍，而不是只调库。

## 技术栈

`PyTorch` · `torchvision` · `torchtext/自写词表` · `NumPy` · `matplotlib` · `scikit-learn`

## 专题清单

| 目录 | 内容 | 关键点 |
|------|------|--------|
| `01.pytorch第一个案例` | 张量、数据类型、自动求导、第一个训练循环 | 线性回归手写梯度下降 |
| `03.pytoch和ndarray` | PyTorch 与 NumPy 的关系、线性代数视角 | 矩阵运算 / 范数 / 特征值 |
| `03.分类` | MLP 手写数字识别、CNN 手写数字识别、信用卡欺诈检测 | 训练 / 验证 / 保存加载 / **断点续训** |
| `04.卷积神经网络` | 卫星图「飞机 / 湖泊」二分类 | 卷积层堆叠、池化、BatchNorm |
| `05.迁移学习和数据增强` | VGG16 迁移学习识别天气、数据增强策略 | `requires_grad` 冻结 / 微调、RandomCrop 等 |
| `06.图像定位` | 目标定位（回归 bbox）+ 语义分割（U-Net 式结构） | 回归 loss 与分割的逐像素分类 |
| `07.文本分类` | 外卖评论情感分析：EmbeddingBag / RNN / LSTM / 双向 RNN | 词表构建、padding、packed sequence |
| `08.序列预测天气` | 时间序列窗口预测 | 滑动窗口 + RNN 多步预测 |
| `09.生产对抗网络` | GAN 生成手写数字 | 生成器 / 判别器对抗训练 |

## 实现要点

- **完整闭环**：每个专题都走完「数据加载 → 模型定义 → 训练 → 评估 → 保存 → 加载验证」，不是只跑 loss。
- **断点续训**：`加载模型参数继续训练.ipynb` 演示了保存 `state_dict` 后恢复训练的写法。
- **中文文本**：自己实现词表与 `collate_fn`，处理变长序列的 padding。
- **训练可视化**：loss / accuracy 曲线画在 Notebook 里，能直接看出过拟合。
