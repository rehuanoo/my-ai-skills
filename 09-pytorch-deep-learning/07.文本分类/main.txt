文本的数值化和变量化


独热编码：每个单词用长度 = 词表总大小的向量表示，对应位置填 1，其余全 0
，如：['I', 'love', 'you'] -> [1, 0, 0], [0, 1, 0], [0, 0, 1]


散列编码（哈希编程）：将单词映射到固定大小的向量上
eg：牛 -> hash(牛) ->  128[10101010...]
    羊 -> hash(羊) ->  128[01010101...]
    猪 -> hash(猪) ->  128[11111111...]


TF-IDF：根据词频和逆文档频率计算权重

词嵌入：根据训练数据


RNN循环神经网络：每次循环都结合了上次循环的结果
                特征：时间维度上循环复用权重，状态横向传递
                目的：建模时序依赖（文本、语音、时间序列）
                梯度问题：序列拉长容易梯度消失 / 爆炸 → 才有 LSTM/GRU
LSTM长短时记忆网络，遗忘门，输入门，单元状态，输出门
GRU门控循环单元，重置门，更新门

 优先选择 LSTM
序列很长（长文本、长语音、时序预测，>200 时间步）
数据集充足，算力足够
需要精细控制记忆保留 / 写入，任务精度要求极高
例如：长文档理解、语音识别
    优先选择 GRU
算力有限、训练时间紧张
中等长度序列，数据量不大
工程快速迭代、baseline 搭建
很多翻译、文本分类任务中 GRU 效果和 LSTM 差距极小
